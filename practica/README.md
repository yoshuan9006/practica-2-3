# Práctica 2 - Construcción de páginas con HTML5

## Introducción

En esta práctica se desarrollaron dos interfaces web utilizando HTML5 como base para organizar la información.

El trabajo consiste en construir la estructura de dos páginas relacionadas con servicios de alojamiento para sitios WordPress. En esta etapa se da prioridad a la organización del contenido, utilizando elementos semánticos, encabezados, listas, párrafos y secciones.

La parte visual y los estilos se trabajarán posteriormente mediante CSS.

## Desarrollo de las páginas

### 1. Página de planes

La primera interfaz está enfocada en presentar diferentes alternativas de alojamiento para WordPress.

Dentro de esta página se incluyeron:

- Encabezado informativo.
- Texto introductorio.
- Tarjeta del plan StartUp.
- Tarjeta del plan GrowBig.
- Tarjeta del plan GoGeek.
- Costos de cada alternativa.
- Lista de beneficios.
- Botones para seleccionar un plan.

Cada tarjeta mantiene una estructura similar para facilitar la comparación de las diferentes opciones.

---

### 2. Página de herramientas

La segunda interfaz presenta diferentes recursos relacionados con la administración de un sitio WordPress.

Los elementos incluidos son:

- Área de atención al usuario.
- Información sobre soporte.
- Personal especializado.
- Tiempo de atención.
- Instalación de servicios.
- Certificados de seguridad SSL.
- Respaldos de información.
- Servicio de correo.
- Entorno de pruebas o staging.
- Herramientas para desarrolladores.
- Servicio CDN.

La información se organizó en diferentes secciones para facilitar su lectura.
